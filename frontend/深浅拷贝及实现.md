### 核心概念

- **浅拷贝**：只复制对象的第一层引用，嵌套对象仍然是共享的。修改嵌套属性会影响原对象。
- **深拷贝**：递归复制所有层级，生成完全独立的新对象，修改新对象不影响原对象。

### 常见实现方式

1. 浅拷贝
   - `Object.assign({}, obj)`
   - `{...obj}` / `[...arr]` 扩展运算符
   - 数组的 `slice()`、`concat()` 等方法

2. 深拷贝
   - `JSON.parse(JSON.stringify(obj))`（不适用于函数、undefined、Symbol等特殊值）
   - 使用第三方库如 Lodash 的 `_.cloneDeep()` 方法
   - 手写递归实现

     ```javascript
     function deepClone(obj, cache = new WeakMap()) {
       // 1. 基本类型、null、函数直接返回原值
       if (obj === null || typeof obj !== "object") {
         return obj;
       }

       // 2. 命中缓存直接返回，解决循环引用
       if (cache.has(obj)) {
         return cache.get(obj);
       }

       // 3. 根据类型创建新容器
       const clone = Array.isArray(obj) ? [] : {};

       // 4. 【关键】先缓存再递归，防止自引用导致栈溢出
       cache.set(obj, clone);

       // 5. 遍历自身可枚举属性（含 Symbol）
       Reflect.ownKeys(obj).forEach((key) => {
         clone[key] = deepClone(obj[key], cache);
       });

       return clone;
     }
     ```
