### 什么是闭包

闭包就是**函数 + 它能访问的外部变量环境的组合**。

简单说，当一个内部函数引用了外部函数的变量，即使外部函数已经执行完毕，这些变量也不会被垃圾回收，而是被内部函数“记住”并持续可用。

### 应用场景

1. **数据私有化与模块化**
   ```javascript
   const createCounter = () => {
     let count = 0; // 私有变量，外部无法直接访问
     return {
       increment: () => ++count,
       getCount: () => count,
     };
   };
   ```
2. **函数柯里化**

   ```javascript
   const multiply = (a) => (b) => a * b;
   const double = multiply(2); // 闭包记住了 a=2
   double(5); // 10
   ```

3. 防抖节流与缓存
   ```javascript
   function debounce(fn, delay) {
     let timer = null; // 闭包保存定时器
     return function (...args) {
       clearTimeout(timer);
       timer = setTimeout(() => fn.apply(this, args), delay);
     };
   }
   ```
