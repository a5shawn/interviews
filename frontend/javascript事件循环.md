### 核心执行机制

JavaScript 是单线程的，所有的代码都在一个线程上执行。为了实现异步操作，JavaScript 引入了事件循环机制。

本质就是一个调度器，用来协调同步代码、异步回调和浏览器渲染，保证主线程不会被卡死。

执行顺序可以简化为四步：

1. 先执行当前所有的同步代码（属于一个宏任务）
2. 同步代码执行完后，立即清空所有微任务队列
3. 浏览器判断是否需要渲染更新页面
4. 开始下一轮宏任务

**微任务在当前宏任务结束后、渲染前立即执行；宏任务要等到下一轮循环才执行**。

requestAnimationFrame 会在渲染前执行，适合做动画。

### 项目实际应用

- 批量 DOM 更新： Vue/React 的 `nextTick` 就是利用微任务来批量更新 DOM，避免频繁重排重绘导致性能问题。
- 长任务拆分： 遇到大数据列表渲染或复杂计算时，用 requestIdleCallback 或 setTimeout(0) 把大任务拆成多个小任务，让出主线程给渲染和用户交互，避免页面卡顿。
- 精准时序控制：
  - 动画用 `rAF` 保证流畅
  - 需要在 DOM 更新后立即读取尺寸时用微任务
  - 数据预加载用 setTimeout(0) 避免阻塞首屏
